# PrintLapse · A1 打印延时视频生成器

把 Bambu Studio 切好片的文件拖进网页，看模型在一台（代码画的）拓竹 A1 里一层层长出来，导出延时视频，直接发短视频平台。不用真打印，也不用相机。

**在线用**：https://jyb635050-ai.github.io/printlapse/

单个 HTML 文件，没有构建步骤，下载下来双击 `index.html` 也能用。

## 怎么用
1. 在 Bambu Studio 里打开模型，打印机选 Bambu Lab A1，点「切片」，再在「文件 → 导出」里选「导出切片文件」，得到 `.gcode.3mf`
2. 拖进网页（也收 `.gcode`）。没切片的 3mf 里没有 G-code，会提示你先去切片
3. 选拍法、机位、比例、清晰度、帧率、时长，点「导出视频」

## 有什么
- **两种拍法**：平滑延时（仿拓竹的平滑模式：每层拍一张，拍的时候喷头让开、热床停在固定位置）／连续（按挤出量均匀推进，喷头和热床跟着 G-code 动）
- **三个机位**：内置相机斜视／环绕一圈／斜上俯视，外加"镜头远近"滑块
- **比例**：16:9、9:16、1:1、4:5、4:3、21:9
- **清晰度**（按短边）：480p／720p／1080p／1440p／4K；**帧率** 24／30／60；**格式** MP4（H.264）／WebM（VP9）
- **多色**：按 G-code 里的换色指令上色，颜色取自切片文件里的耗材颜色；多盘文件可以选盘

## 几件值得知道的事
- **画面只由 G-code 决定。** 挤出路径一段一段照 G-code 画，圆弧展开成小段；热床外的挤出（换色吐料）不画，擦料塔会画。
- **导出帧数和帧率是精确的。** 第 i 帧的时间戳固定是 i/fps 秒，画面只看帧号、不看时钟，机器卡不卡都不影响成片。时长里含片尾停留 1 秒。
- **速度**：750 层、11.8MB G-code 的样本打开不到 1 秒，1080p30 10 秒视频几秒导完（Intel 核显实测）。
- 打印机外观是代码画的简化造型，神似 A1，不含拓竹的任何图片、模型文件或商标。

## 开发
- `node verify.js`：判卷。起本地服务和无头 Chrome，像用户一样往文件框放样本、改选项、点导出，收下真实下载的视频，只用 ffprobe 和抽帧像素判：尺寸、帧数、编码、模型是否逐层长高、四色是否都在、三个机位是否真不同、没切片的 3mf 是否被拒、大文件速度。
- `node verify.js --prove` / `--break=flat|onecolor|samecam`：故意弄坏样本或用例，证明对应判据真的会变红。
- `node verify.js --url https://jyb635050-ai.github.io/printlapse/`：判线上页面。
- `python tools/make_fixtures.py`：用本机 Bambu Studio 命令行重新切 `fixtures/` 里的三个 A1 样本（配置继承要自己展开，脚本里写了原因）。
- `node tools/screenshot.js <样本> <输出.png> [机位] [进度0-1000] [比例] [拍法] [远近]`：截界面图。
